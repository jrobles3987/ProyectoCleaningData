# Getting and Cleaning Data Project

Este repositorio contiene el proyecto final del curso Getting and Cleaning Data.

Archivos:

run_analysis.R
Script que descarga, limpia y transforma el dataset.

CodeBook.md
Describe las variables y transformaciones realizadas.

tidy_dataset.txt
Dataset final ordenado con el promedio de cada variable por actividad y sujeto.

Para ejecutar:

1. Ejecutar run_analysis.R en R
2. El script descargará y procesará los datos automáticamente
3. Se generará tidy_dataset.txt
